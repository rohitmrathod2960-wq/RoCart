# RoCart – Watches for Men

RoCart is a modern and responsive e-commerce website for men's watches.  
The project is built to provide users with a smooth shopping experience, stylish UI, and easy navigation across products.

Live Demo: https://ro-cartwatchesformen.netlify.app/

##  Features

- Responsive design for all devices
- Modern UI/UX
- Product listing section
- Watch categories and collections
- Add to cart functionality
- Smooth navigation
- Fast loading performance
- Attractive homepage banners

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Netlify (Deployment)
